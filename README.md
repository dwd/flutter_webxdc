# flutter_webxdc

A Flutter plugin that implements the [webxdc specification](https://webxdc.org/docs/spec/index.html)
to enable interactive, embeddable mini apps (`.xdc` archives) in Flutter applications.

## Status

This plugin is currently in the design phase. It targets the following platforms:
- **Android**
- **Desktop** (Linux, macOS, Windows)
- **Web**

For the detailed architecture and roadmap, please see [doc/design.md](doc/design.md).

## Usage

Usage examples will be provided once the platform hosting implementation is complete.

## Additional information

Please refer to [doc/design.md](doc/design.md) for the target architecture,
the JS API contract, and testing strategy. Contributions are welcome once the
plugin scaffolding is established.
